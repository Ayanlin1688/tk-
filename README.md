# TK 图文工作台 · 使用说明

本地桌面工具：**导入参考图文 → 自动分析结构与排版指纹 → 批量生成多套「同骨架、全新内容」的 TK 图文 → 直接发布**。

- 目标市场：美国（英语 + 西语，面向拉美裔人群）
- 界面语言：中文
- 图文语言：**自动跟随参考图**（参考图西语→出西语，英语→出英语，需 AI 精分析识别）/ 西语 / 英语 / 双语混合
- 生图方式：**3 路并行 AI 生图 + 单张失败自动重试**，多套多张不再串行干等
- 排版机制：每张参考图提取「排版指纹」（文字区坐标/字号比例/对齐/配色/底条/贴纸），新图文逐张跟随，不是固定模板
- 文案机制：AI 按参考图语气模仿，**长度按参考图文字区容量自适应**（区小文案短、区大文案长），语言随参考图
- 渲染原生感：手绘荧光划痕、波浪下划线、价格数字黄色高亮、指向手势贴纸，弱化模板感
- 价格页增强：**划线原价**（如 ~~$49.99~~ → $25.99，灰色划线+黄色现价，更接近真实 TikTok 促销条）
- 钩子关键词强调：标题里按种子挑一个词用**参考图强调色**标出，模仿真人圈重点
- 产品图**可多选**：多张产品图自动按套轮换（20 套轮换不重样），可单独删除
- 文案池口语化扩充：4 个人格各新增 2-4 条更口语、带 emoji 的钩子/卖点/CTA
- AI 精分析失败**可见化**：失败自动重试 1 次后仍失败，界面明确提示「N 张已回退规则分析」并列出原因
- 默认内置产品：QAWAFI Voyage Nova 女士香水（玫瑰+红果香调），产品信息可在界面中直接修改

---

## 一、怎么启动

双击 **TK图文工作台.exe** 即可（首次启动约 3-5 秒，需 Windows 10/11）。

> 若提示找不到 WebView2 运行时：在浏览器搜索「WebView2 Runtime 下载」安装微软官方运行时后重启应用。

## 二、四步操作流程

### 第0步（必做）：AI 生图设置
裂变生成需要先接生图 API（OpenAI 兼容接口）：
1. 在 **STEP 3** 找到「🤖 AI 裂变生图」设置区
2. 填好接口地址（默认已填你的中转地址）和 API 密钥
3. 点「🔌 测试连接」→ 生图模型下拉框自动列出可用模型（已过滤掉视频模型）→ 选中一个（如 `gpt-image-2`）
4. （可选）填「分析模型」：多模态模型名（如 `gemini-3.8-flash`），勾选「用分析模型精分析参考图排版」后，分析参考图时用 AI 识别图文结构，排版更准
5. 点「💾 保存设置」（密钥只保存在本机 `ai_config.json`，不发任何第三方）

### 第1步：导入参考图文
- 点击「＋ 选择参考图片」，**把你想要模仿的那套轮播图文的所有图都选上**（钩子页/卖点页/产品页/价格页，PNG/JPG/WEBP）。
- 导入后右侧显示缩略图，可删除不需要的。
- **生成的张数 = 你导入的参考图张数**：第1张对应你的第1张参考图（钩子），最后一张对应最后一张（价格页），中间逐张对应，排版都跟着参考图走。

### 第2步：自动分析
- 点击「开始分析」（默认规则分析，不花额度；若你在第0步填了分析模型并勾选开关，则用 AI 精分析）。
- 工具逐张提取：背景主色 / 强调色 / 文字色、每张图的文字区与图片区位置（排版骨架）。
- 右侧显示「文字区标注图」（绿框=文字区，蓝框=图片区），用于确认识别是否准确。

### 第3步：配置生成
- 语言：**自动跟随参考图（默认）**——参考图是西语就出西语、英语就出英语（需 AI 精分析识别出语言；未开启精分析时回退西语）/ 西语 / 英语 / 双语各半
- 套数：1-20 套
- **图文风格（账号人格）**：默认「自动轮换」= 每套随机一种真实 TikTok 账号人格；或固定选某个人格
  - **APG 省钱反讽**（西语）：贵vs便宜对比、幽默反讽文案、黄色荧光条
  - **ConMariaa 闺蜜悬念**（西语）：警示式钩子、**黄色大字**叠字、箭头指向产品
  - **Jonhy 直白实用**（英语）：紧迫 CTA、白字白荧光条、直白卖点
  - **Viviana 俏皮梗**（西语）：网络梗文案、粉色荧光条、闺蜜口吻
  - 每套的文案从人格文案池按种子组合，**不是同一条文案换数字**；排版（字体/颜色/高亮/贴纸）跟着人格走
- **AI裂变生图开关（默认开）**：第1张~倒数第2张都用 AI 生成**全新满幅实拍画面**（第1张=钩子场景、中间=产品+场景），人物×场景×情节每套不重样，钩子像参考图那样一句大字叠在画面上；**最后一张不 AI 生成，直接用你上传的产品图**（若没上传产品图才回退 AI 生成产品特写）；关闭开关则全部回退本地排版（不花额度）
- 产品图（**可多选**）：**建议上传**。价格页（最后一张）自动使用你的真实产品图；**传多张则按套自动轮换**（如传 2 张、生成 20 套 → 2 张图交替出现在价格页，成品不重样）。不传则用内置香水瓶素材。
- 产品信息：默认已填 QAWAFI Voyage Nova 数据，可直接改成你自己的产品。**划线原价**（如 $49.99）可选填，填了价格条自动显示「~~原价~~ 现价」。

### 第4步：一键生成 + 导出
- 点击「🚀 开始裂变生成」：**AI 画面 3 路并行生成**（单张约 15-30 秒，多套多张总耗时约快 3 倍），界面实时显示进度；生成中途可点「⏹ 停止生成」（已完成的套保留）。
- **单张失败自动重试 2 次**，仍失败自动回退本地排版，并在结果里列出失败清单（不再静默吞掉）。
- **每套 = 参考图张数张图**（全部为 AI 全新满幅画面 + 少量叠字，排版跟随参考图）+ **发布包.txt**。
- 生成完成后点「📦 打包ZIP」一键打包全部成品，自动打开输出文件夹；点「打开输出文件夹」直接拿成品。

## 三、输出内容（每套一个文件夹）

| 文件 | 内容 |
|------|------|
| 图1_钩子页.png | 1080×1920，**AI 生成的全新满幅实拍画面** + **只叠一句钩子大字**（像真实 TikTok 钩子页：一张画面+一句话），可直接发 TikTok |
| 图2~N-1_卖点页.png | **AI 生成的产品+场景满幅实拍画面** + 卖点叠字 |
| 图N_价格页.png | **你上传的真实产品图**（多张则按套轮换，不再 AI 画瓶）+ 一句卖点 + 黑底价格条（50% OFF · ~~原价~~ · 现价 · link en mi carrito）+ 指向箭头 |
| 发布包.txt | 完整发布素材：叠字、正文、话题标签、评论钩子、置顶评论、英文生图提示词 |

> 参考图文导入几张，每套就生成几张；第1张只放一句钩子，最后一张用你上传的产品图，文字少量叠在图上（与参考图风格一致）。

### 发布包包含（可直接复制发布）
- ◆ 图1叠字（钩子）
- ◆ 图2价格卡
- ◆ 发布正文（西语/英语）
- ◆ 话题标签（8-12个，含 #QAWAFI #voyagenova #tiktokshop）
- ◆ 评论钩子 + 置顶评论
- ◆ 图1英文生图提示词（用于 AI 生成实拍素材图，人物×场景×情节每套不重样）
- ◆ 图2产品图提示词

## 四、五个内容角度（每套自动轮换）

1. **吸引力 POV**（英语）——"the perfume that makes him surrender"
2. **玫瑰约会叙事**（西语）——"Huele a Rosas"
3. **平价贵感**（西语）——"$26 vs $200"
4. **留香实测**（通用）——"早上7点喷下午3点还在"
5. **闪购紧迫**（西语）——"倒计时还剩 XX 小时"

每套自动换一个角度 + 换一组人物/场景/情节生图提示词 + 换一套配色，避免同质化。

---

## 五、生产建议（防限流防封号）

- 每套图文发布间隔至少 2 小时，单账号每天 3-5 条。
- 多账号必须一账号一独立 IP（住宅代理），不要短时间集中发布。
- 发布前人工检查：产品功效/价格/承诺类文案、商品挂载链接。
- 每周复盘：记录每套的播放/收藏/点击，把高表现的角度+配色固定下来。

```
TK图文工作台/

├─ output/               # 生成结果（每套一个文件夹）

│       │   ├─ 图2_价格页.png

│       └─ ...

├─ index.html            # 界面文件（打包内置，无需修改）
├─ webapp.py             # 主程序源码
├─ analysis.py           # 分析引擎源码
├─ generator.py          # 生成引擎源码
└─ content.py            # 双语文案素材库（可自行扩充）
```

## 七、进阶：扩充你自己的文案库

打开 `content.py`，在 `HOOKS`（钩子）、`CAPTIONS`（正文）、`TAGS`（标签）等字典里按同样格式添加条目，重启应用即生效。适用于换产品、换赛道（如美妆、服饰）时重新组织素材。

4 个人格（APG / ConMariaa / Jonhy / Viviana）的口语化文案池在 `styles.py` 对应人格的 `hooks / claims / ctas` 里，同样可直接扩充。
